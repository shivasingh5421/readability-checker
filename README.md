# Chapter Readability Checker · Editorial Pro

A client-side literary analysis tool that calculates readability using multiple established metrics and pinpoints the 5 most demanding sentences with linguistic breakdown.

## Features
- **Sentence Hardness Index (SHI)**: Evaluates cognitive burden, polysyllabic density, clause nesting, and nominalization.
- **Multi-Formula Engine**: Computes Flesch Reading Ease, Flesch-Kincaid Grade, Gunning Fog, Coleman-Liau, SMOG, and ARI.
- **Interactive Inspection**: Click-to-inspect sentences, dynamic heatmap spectrum, complex word wavy underlining.
- **100% Client-Side**: No backend required, zero data sent over the network.

## Deployment to Vercel
Deploy directly via GitHub repository import or Vercel CLI.
